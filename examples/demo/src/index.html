Multiline Menubar Plugin

Menu Bar

This demo uses a native NSStatusItem with a custom NSView to render two lines in the macOS menu bar, matching the Stats widget reference.

Click the menu bar item to open the popup.

Hover the menu bar item to see enter/leave events.

Right-click for the menu (Version / Quit).

Colors

Pick a color for each line. "Reset to system color" reverts to macOS's default menu-bar text color (follows light/dark mode).

Bold

Force the top and/or bottom line bold, independent of the layout. Each line is controlled separately; clearing a checkbox leaves that line's weight to the layout (emphasized = regular, other = light).

Font family

Swap the top and/or bottom line to a specific font family — the name shown in macOS Font Book, e.g. Menlo or PingFang SC. Leave a field empty to keep the system font for that line. Unknown names fall back to the system font, and the weight from the layout / bold controls is still honored.

Monospaced digits

Render a line with the system monospaced-digit font so every digit keeps the same width — frequently-updating numeric text (like the simulated speed below) does not jitter. An explicit font family above takes precedence over this toggle.

Speed simulation

Push a random up/down speed to the menu bar once per second (up on the top line, down on the bottom). With monospaced digits enabled the numbers change width-stable; the plugin's render cache skips repaints whenever the formatted text is unchanged.
