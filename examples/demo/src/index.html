Multiline Menubar Plugin

Menu Bar

This demo uses a native NSStatusItem with a custom NSView to render two lines in the macOS menu bar, matching the Stats widget reference.

Click the menu bar item to open the popup.

Hover the menu bar item to see enter/leave events.

Right-click for the menu (Version / Quit).

Colors

Pick a color for each line. "Reset to system color" reverts to macOS's default menu-bar text color (follows light/dark mode).
