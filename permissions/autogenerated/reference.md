## Default Permission

Default permissions for the multiline-menubar plugin

#### This default permission set includes the following:

- `allow-create`
- `allow-destroy`
- `allow-set-text`
- `allow-set-font-sizes`
- `allow-set-tooltip`
- `allow-set-visible`
- `allow-set-menu`
- `allow-remove-menu`
- `allow-get-rect`
- `allow-set-popup-window`
- `allow-set-auto-popup`
- `allow-open-popup`
- `allow-close-popup`
- `allow-toggle-popup`
- `allow-show`
- `allow-hide`
- `allow-is-visible`
